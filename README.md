# whats-in-the-fridge-vault

База знань (Obsidian vault) застосунку **«Що в холодильнику»**
([PashaMylkus/whats-in-the-fridge](https://github.com/PashaMylkus/whats-in-the-fridge)).

Репозиторій навмисно відокремлений від репозиторію застосунку: агент Claude Code
не має до нього прямого доступу і працює з ним лише через інструменти MCP-сервера
`fridge-kb` (ПР № 3).

## Структура

| Директорія | Тип нотатки | Зміст |
|---|---|---|
| `Concepts/` | `concept` | поняття предметної області (продукт, термін придатності, рецепт…) |
| `Components/` | `component` | заплановані модулі й компоненти кодової бази |
| `Decisions/` | `decision` | архітектурні рішення (ADR) |
| `Glossary/` | `glossary` | терміни проєкту |
| `Templates/` | — | шаблони frontmatter для core-плагіна Templates |
| `tools/` | — | `validate-vault.mjs` — перевірка конвенцій і зв'язності |

Точка входу — [`MOC-Застосунок.md`](MOC-Застосунок.md); трасування вимог —
[`MOC-Вимоги.md`](MOC-Вимоги.md); правила оформлення — [`Конвенції vault.md`](Конвенції%20vault.md).

## Робота з vault

1. Obsidian → **Open folder as vault** → обрати клон цього репозиторію.
2. Graph view: `Ctrl/Cmd + G` (кольори груп за папками налаштовані в `.obsidian/graph.json`).
3. Нова нотатка: Templates → обрати шаблон типу, заповнити `id` і `title`.
4. Перевірка перед комітом:

```bash
node tools/validate-vault.mjs
```

Скрипт перевіряє обов'язкові поля frontmatter для кожного типу, відповідність
папки типу, унікальність `id` і назв, розв'язність усіх `[[wiki-посилань]]`,
досяжність кожної нотатки з `MOC-Застосунок` і відсутність сиріт.
