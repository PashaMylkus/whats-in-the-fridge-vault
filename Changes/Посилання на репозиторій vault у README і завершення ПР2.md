# Посилання на репозиторій vault у README і завершення ПР2

У `README.md` репозиторію застосунку текстову згадку бази знань замінено посиланням на GitHub-репозиторій `whats-in-the-fridge-vault`. Це окремий [[Vault|vault]] згідно з [[ADR-0005 Окремий репозиторій бази знань із доступом через MCP]].

У таблиці стану практичних робіт ПР2 «База знань (Obsidian vault) і джерела даних» позначено як виконану. ПР3–ПР5 лишаються в роботі.

Зміна стосується лише документації: коду компонентів вона не зачіпає.
