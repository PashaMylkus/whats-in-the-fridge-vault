# Модуль рецептів

Модуль [[API-сервер|API-сервера]] для каталогу [[Рецепт|рецептів]], [[Підбір рецептів|підбору]] та [[Приготування рецепта|приготування]].

## Ендпоінти

| Метод і шлях | Призначення | Доступ | FR |
|---|---|---|---|
| `GET /api/recipes` | каталог із пошуком | user | FR-04 |
| `GET /api/recipes/:id` | картка рецепта | user | FR-04 |
| `POST`, `PATCH`, `DELETE /api/recipes/:id` | керування каталогом | admin | FR-04 |
| `GET /api/recipes/suggestions` | ранжований список з `coverage` і відсутніми інгредієнтами | user | FR-05 |
| `POST /api/recipes/:id/cook` | атомарне списання продуктів | user | FR-06 |

## Залежності

- [[Сервіс підбору рецептів]] — обчислення `suggestions`.
- [[Модуль продуктів]] (репозиторій продуктів) і [[Модуль журналу та статистики]] — списання й подія `consumed` в одній транзакції [[База даних|БД]].
- Каталог наповнюється [[Seed-дані|seed-даними]] при `prisma db seed`.
