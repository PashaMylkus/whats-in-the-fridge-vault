# Модуль автентифікації

Модуль [[API-сервер|API-сервера]] для реєстрації, входу та сесій [[Користувач|користувачів]] (див. [[ADR-0006 Сесія через JWT у HttpOnly cookie]]).

## Ендпоінти

| Метод і шлях | Призначення |
|---|---|
| `POST /api/auth/register` | реєстрація (email, пароль ≥ 8 символів) |
| `POST /api/auth/login` | вхід, встановлення cookie `session` |
| `POST /api/auth/logout` | видалення cookie |
| `GET /api/auth/me` | поточний користувач |

## Безпека (NFR-02)

- Паролі — лише хеш bcrypt (cost 12); пароль ніколи не повертається й не логується.
- JWT підписується секретом `JWT_SECRET` з `.env` (агенту заборонено читати `.env` — guardrail block).
- Middleware `requireAuth` додає `req.user` і використовується всіма модулями, крім `/api/auth/*`.
- Обмеження частоти спроб входу: 5 за хвилину з однієї IP-адреси.
