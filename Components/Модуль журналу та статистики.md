# Модуль журналу та статистики

Модуль [[API-сервер|API-сервера]], що веде [[Журнал подій]] і рахує статистику.

## Інтерфейси

- Внутрішній: `eventsService.record(tx, { userId, productId, type, quantity })` — викликається з [[Модуль продуктів]], [[Модуль рецептів]], [[Модуль списку покупок]] **у межах їхньої транзакції**.
- `GET /api/events?from=&to=&type=` — журнал за період.
- `GET /api/stats?period=week|month` — агрегати: спожито, викинуто, частка викинутих, топ категорій, що псуються.

Записи журналу не змінюються й не видаляються через API (append-only).
