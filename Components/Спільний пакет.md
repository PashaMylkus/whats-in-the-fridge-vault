# Спільний пакет

Пакет `packages/shared` — єдине джерело схем, типів і доменної логіки для [[Веб-клієнт|веб-клієнта]] та [[API-сервер|API-сервера]]. Не залежить від Express, React чи Prisma (див. [[ADR-0003 Доменна логіка як чисті функції]]).

## Вміст

```
packages/shared/src/
  schemas/   # zod-схеми: product, recipe, shopping-item, auth, event
  types/     # типи, виведені з схем (z.infer)
  domain/
    freshness.ts        # статуси свіжості
    recipe-matching.ts  # підбір рецептів
    normalize.ts        # нормалізація назв продуктів
  constants.ts          # EXPIRING_THRESHOLD_DAYS, переліки категорій, одиниць
```

Доменні функції описано в нотатках [[Сервіс статусів свіжості]] і [[Сервіс підбору рецептів]]; переліки — у [[Категорія продукту]], [[Одиниця виміру]] та [[Місце зберігання]].

## Правила

- Покриття тестами ≥ 80 % (NFR-04).
- Будь-яка зміна схеми, що ламає сумісність, супроводжується міграцією [[База даних|БД]] і оновленням нотаток [[Продукт]] / [[Рецепт]].
