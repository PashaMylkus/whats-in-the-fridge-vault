# Сервіс статусів свіжості

Чиста функція у [[Спільний пакет|спільному пакеті]], що реалізує правило [[Статус свіжості|статусу свіжості]].

## Контракт

```ts
type FreshnessStatus = 'fresh' | 'expiring' | 'expired';

function getFreshnessStatus(
  expiresAt: string | null,   // 'YYYY-MM-DD'
  today: string,              // 'YYYY-MM-DD' — передається явно, без Date.now()
  thresholdDays = EXPIRING_THRESHOLD_DAYS,
): FreshnessStatus;

function daysLeft(expiresAt: string, today: string): number;
```

`today` передається параметром, щоб функція була детермінованою і тестувалася без мокання часу.

## Тести

Обов'язкові випадки — у розділі «Граничні випадки» нотатки [[Статус свіжості]]. Використовується в [[Модуль продуктів]] і [[Сервіс підбору рецептів]].
