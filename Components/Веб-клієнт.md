# Веб-клієнт

Односторінковий застосунок (SPA) на React 19 + Vite + TypeScript. Звертається до [[API-сервер|API-сервера]] через HTTP і використовує zod-схеми та типи зі [[Спільний пакет|спільного пакета]].

## Сторінки (план)

| Маршрут | Призначення | FR |
|---|---|---|
| `/` | Продукти з фільтрами, підсвічування [[Статус свіжості|статусу]] | FR-01–03 |
| `/expiring` | «Скоро зіпсується» | FR-03 |
| `/recipes`, `/recipes/:id` | Каталог і картка [[Рецепт|рецепта]], кнопка «Приготувати» | FR-04, FR-06 |
| `/suggestions` | [[Підбір рецептів]] | FR-05 |
| `/shopping` | [[Список покупок]] | FR-07 |
| `/stats` | Статистика з [[Журнал подій|журналу]] | FR-09 |
| `/login`, `/register` | Вхід і реєстрація | FR-08 |

## Конвенції

- Серверний стан — лише через TanStack Query (хуки `useProducts`, `useRecipes`…); глобальний стор не використовується.
- Структура: `src/pages/`, `src/features/<модуль>/` (компоненти + хуки), `src/shared/` (UI-кіт).
- Тести — Vitest + React Testing Library.
