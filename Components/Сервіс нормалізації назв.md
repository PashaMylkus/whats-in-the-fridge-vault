# Сервіс нормалізації назв

Чиста функція у [[Спільний пакет|спільному пакеті]], що зводить назву [[Продукт|продукту]] чи [[Інгредієнт рецепта|інгредієнта]] до канонічної форми для зіставлення ([[Підбір рецептів]], об'єднання позицій [[Список покупок|списку покупок]]).

## Контракт

```ts
function normalizeName(name: string): string;
function isSameName(a: string, b: string): boolean; // normalizeName(a) === normalizeName(b)
```

## Правила (у порядку застосування)

1. Unicode-нормалізація NFC (літера з комбінованим знаком і готова літера — однакові).
2. Нижній регістр за правилами української мови (`toLocaleLowerCase('uk')`).
3. Усі варіанти апострофа (`’ ʼ ` ´ ‘`) замінюються на `'` («м’ясо» = «м'ясо» = «мʼясо»).
4. Будь-яка послідовність пробільних символів (пробіл, таб, перенос) — один пробіл.
5. Пробіли й розділові знаки `. , ; : ! ? « » " -` на початку й у кінці прибираються; усередині назви — зберігаються. **Дужки не прибираються**, щоб не розривати уточнення: «рис басматі (довгий)» → «рис басматі (довгий)».

Синоніми («томат» / «помідор») нормалізацією **не** обробляються — для них поле `aliases` інгредієнта.

## Граничні випадки для тестів

- `'  Молоко  '` → `'молоко'`; `'МОЛОКО 2,5%'` → `'молоко 2,5%'`.
- `'Сир\tтвердий\n'` → `'сир твердий'`.
- `'«Гречка»'` → `'гречка'`; `'яйця!!!'` → `'яйця'`.
- `''` → `''`; `' ... '` → `''`.
- `'Рис (довгий)'` → `'рис (довгий)'`.
- `isSameName('М’ЯСО', 'мʼясо')` → `true`; `isSameName('томат', 'помідор')` → `false`.
