# Модуль списку покупок

Модуль [[API-сервер|API-сервера]], що реалізує [[Список покупок]].

## Ендпоінти

| Метод і шлях | Призначення |
|---|---|
| `GET /api/shopping-items` | список позицій |
| `POST /api/shopping-items` | додати вручну (з об'єднанням однакових позицій) |
| `POST /api/shopping-items/from-recipe/:recipeId` | додати відсутні інгредієнти [[Рецепт|рецепта]] |
| `PATCH /api/shopping-items/:id` | змінити кількість / назву |
| `POST /api/shopping-items/:id/purchase` | «куплено» → створити [[Продукт]] через [[Модуль продуктів]] |
| `DELETE /api/shopping-items/:id` | видалити позицію |

Відсутні інгредієнти отримуються з тієї самої логіки, що й у [[Модуль рецептів|модулі рецептів]] (`missing` із [[Сервіс підбору рецептів|сервісу підбору]]).
