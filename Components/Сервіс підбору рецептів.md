# Сервіс підбору рецептів

Чиста функція у [[Спільний пакет|спільному пакеті]], що реалізує алгоритм [[Підбір рецептів|підбору рецептів]].

## Контракт

```ts
interface RecipeSuggestion {
  recipeId: string;
  coverage: number;            // 0..1
  expiringUsed: number;
  missing: IngredientRef[];
  score: number;
}

function rankRecipes(
  recipes: RecipeWithIngredients[],
  products: ProductWithStatus[],   // статус уже обчислено
): RecipeSuggestion[];
```

## Залежності та тести

- Використовує нормалізацію назв і [[Сервіс статусів свіжості]] (через вхідні дані `ProductWithStatus`).
- Unit-тести на фіксованому наборі з [[Seed-дані|seed-даних]] перевіряють точний порядок результатів.
- Викликається з [[Модуль рецептів]].
