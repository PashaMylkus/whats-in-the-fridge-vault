# Модуль продуктів

Модуль [[API-сервер|API-сервера]], що реалізує облік [[Продукт|продуктів]].

## Ендпоінти

| Метод і шлях | Призначення | FR |
|---|---|---|
| `GET /api/products` | список з параметрами `search`, `category`, `location`, `status`, `sort` | FR-01, FR-02 |
| `POST /api/products` | створення | FR-01 |
| `GET /api/products/:id` | один продукт | FR-01 |
| `PATCH /api/products/:id` | редагування | FR-01 |
| `DELETE /api/products/:id` | видалення (`?reason=discarded` → подія `discarded`) | FR-01, FR-09 |
| `GET /api/products/expiring` | продукти зі статусом `expiring` і `expired` | FR-03 |
| `GET /api/products/export` | експорт JSON | FR-10 |
| `POST /api/products/import` | імпорт JSON | FR-10 |

## Залежності

- [[Сервіс статусів свіжості]] — додає поле `status` до кожного продукту у відповіді.
- [[Модуль журналу та статистики]] — запис подій `added`, `updated`, `discarded`.
- Фільтр `status` застосовується після обчислення статусу; решта фільтрів — на рівні SQL.
