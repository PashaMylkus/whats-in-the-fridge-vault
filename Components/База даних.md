# База даних

SQLite-файл, доступ через Prisma ORM (див. [[ADR-0002 SQLite і Prisma як сховище даних]]). Схема — `apps/api/prisma/schema.prisma`, міграції — `apps/api/prisma/migrations/`, [[Seed-дані|seed-дані]] — `apps/api/prisma/seed/`.

## Моделі (план)

| Модель | Ключові поля | Нотатка |
|---|---|---|
| `User` | email (unique), passwordHash, role | [[Користувач]] |
| `Product` | userId, name, normalizedName, category, quantity, unit, location, purchasedAt, expiresAt | [[Продукт]] |
| `Recipe` | title (unique), steps (JSON), cookingTimeMin, servings | [[Рецепт]] |
| `RecipeIngredient` | recipeId, name, normalizedName, quantity, unit, optional | [[Інгредієнт рецепта]] |
| `ShoppingItem` | userId, name, quantity, unit, purchased | [[Список покупок]] |
| `Event` | userId, productId?, type, quantity, createdAt | [[Журнал подій]] |

## Правила

- Схема змінюється лише через `prisma migrate dev` (рівень guardrails — warn); `prisma migrate reset` заборонено агенту (block).
- Індекси: `Product(userId, expiresAt)`, `Product(userId, normalizedName)` — для FR-02/FR-05.
