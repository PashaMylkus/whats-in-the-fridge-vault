# Guardrail

*Guardrail*

Явне обмеження дій агента одного з трьох рівнів: **allow** (дозволено), **warn** (потрібне підтвердження людини), **block** (заборонено). У Claude Code реалізується через `permissions` і hooks (див. [[Конфігурація agent harness]]).
