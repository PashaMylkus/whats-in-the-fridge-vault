# Agent harness

*Agent harness*

Інженерна інфраструктура навколо LLM-агента: джерела даних, knowledge layer (цей [[Vault|vault]]), [[Skill|skills]], [[Guardrail|guardrails]], оркестрація та оцінювання. Прискорює розробку застосунку, не будучи його частиною (див. [[Конфігурація agent harness]]).
