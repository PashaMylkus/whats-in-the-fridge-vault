# ADR-0002. SQLite і Prisma як сховище даних

## Контекст

Потрібна реляційна БД із транзакціями ([[Приготування рецепта]] списує кілька продуктів атомарно), яка запускається без сервера на будь-якій ОС (NFR-07) і легко відтворюється для тестів.

## Рішення

SQLite як файл БД, Prisma ORM для схеми, міграцій, типізованого клієнта й seed-скрипта (див. [[База даних]]).

## Розглянуті альтернативи

- PostgreSQL у Docker — ближче до production, але вимагає Docker і окремого процесу.
- Drizzle ORM — легший, але Prisma має зрілий механізм міграцій і краще знайома LLM.
- Без ORM (better-sqlite3 + SQL) — більше ручного коду й ризик SQL-помилок агента.

## Наслідки

- (+) Тестова БД створюється за секунди: окремий файл на тестовий прогін.
- (−) Обмежена конкурентність запису — неважливо для одного користувача на локальній машині.
- (−) Перехід на PostgreSQL потребуватиме перевірки типів дат; схема пишеться так, щоб це було можливо.
