# Місце зберігання

**Місце зберігання** — де саме вдома лежить [[Продукт]]. Використовується для фільтрації (FR-02) і групування списку продуктів у [[Веб-клієнт|веб-клієнті]].

## Допустимі значення

| Код | Назва в UI |
|---|---|
| `fridge` | Холодильник |
| `freezer` | Морозилка |
| `pantry` | Комора |

## Правила

- Значення — перелік (enum) у zod-схемі [[Спільний пакет|спільного пакета]] і в Prisma-схемі [[База даних|бази даних]]; нові значення додаються лише через міграцію.
- Місце зберігання **не змінює** [[Термін придатності]] автоматично: користувач сам коригує дату, якщо, наприклад, переносить м'ясо в морозилку.
