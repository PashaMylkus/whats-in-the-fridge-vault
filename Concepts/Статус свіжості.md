# Статус свіжості

**Статус свіжості** — похідна (не збережена) ознака [[Продукт|продукту]], яка показує, наскільки близько закінчення його [[Термін придатності|терміну придатності]].

## Правило обчислення

`daysLeft = expiresAt − today` (у календарних днях)

| Статус | Умова | Відображення |
|---|---|---|
| `fresh` | `expiresAt = null` або `daysLeft > 3` | звичайний рядок |
| `expiring` | `0 ≤ daysLeft ≤ 3` | жовте підсвічування, список «Скоро зіпсується» |
| `expired` | `daysLeft < 0` | червоне підсвічування |

Поріг 3 дні — константа `EXPIRING_THRESHOLD_DAYS` у [[Спільний пакет|спільному пакеті]]; функція приймає й інший поріг — ціле число ≥ 0, інакше `RangeError`.

## Граничні випадки для тестів

- `expiresAt` = сьогодні → `expiring` (0 днів).
- `expiresAt` = сьогодні + 3 → `expiring`; сьогодні + 4 → `fresh`.
- `expiresAt` = учора → `expired`.

## Зв'язки

- Обчислюється чистою функцією в [[Сервіс статусів свіжості]] (див. [[ADR-0003 Доменна логіка як чисті функції]]).
- Використовується в [[Модуль продуктів|фільтрі за статусом]] і як пріоритет у [[Підбір рецептів|підборі рецептів]].
