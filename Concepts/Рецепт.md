# Рецепт

**Рецепт** — інструкція приготування страви: назва, перелік [[Інгредієнт рецепта|інгредієнтів]] із кількістю, кроки, час приготування та кількість порцій.

## Атрибути

| Поле | Тип | Примітка |
|---|---|---|
| `title` | рядок | унікальний у каталозі |
| `ingredients` | список [[Інгредієнт рецепта]] | ≥ 1 обов'язковий інгредієнт |
| `steps` | список рядків | ≥ 1 крок |
| `cookingTimeMin` | ціле > 0 | використовується як другорядний критерій сортування |
| `servings` | ціле > 0 | |

## Правила

- Каталог спільний для всіх [[Користувач|користувачів]]; створювати й редагувати рецепти може лише адміністратор.
- Початковий каталог (≥ 30 рецептів) завантажується з [[Seed-дані|seed-даних]].

## Зв'язки

- Реалізується в [[Модуль рецептів]].
- Ранжується [[Підбір рецептів|підбором рецептів]]; може бути [[Приготування рецепта|приготований]]; відсутні інгредієнти потрапляють у [[Список покупок]].
