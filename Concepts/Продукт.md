# Продукт

**Продукт** — одиниця обліку в застосунку: конкретна їжа, що зберігається вдома в певній кількості й має (або не має) [[Термін придатності|термін придатності]]. Продукт завжди належить одному [[Користувач|користувачу]].

## Атрибути

| Поле | Тип | Обов'язкове | Примітка |
|---|---|---|---|
| `name` | рядок 1–100 символів | так | Нормалізується (нижній регістр, без зайвих пробілів) для зіставлення з [[Інгредієнт рецепта|інгредієнтами]] |
| `category` | [[Категорія продукту]] | так | Довідник фіксований |
| `quantity` | число > 0 | так | Після списання може стати 0 — тоді продукт вважається використаним |
| `unit` | [[Одиниця виміру]] | так | |
| `location` | [[Місце зберігання]] | так | |
| `purchasedAt` | дата | так | За замовчуванням — сьогодні |
| `expiresAt` | дата | ні | `null` для продуктів без терміну (сіль, цукор) |

## Правила

- [[Статус свіжості]] не зберігається в БД, а обчислюється з `expiresAt` при кожному запиті.
- Будь-яка зміна продукту записується в [[Журнал подій]].
- Продукти можна експортувати та імпортувати у JSON (FR-10) — формат збігається зі схемою zod у [[Спільний пакет|спільному пакеті]].

## Зв'язки

- Реалізується в [[Модуль продуктів]], зберігається в [[База даних|базі даних]] (модель `Product`).
- Використовується в [[Підбір рецептів|підборі рецептів]] і списується під час [[Приготування рецепта|приготування]].
- З'являється з [[Список покупок|списку покупок]], коли позицію позначено «куплено».
